# 🧩 Rede Chromos Matcher

Sistema web desenvolvido em **PHP / Laravel** para cruzamento automatizado de dados cadastrais e identificação de alunos aprovados a partir de arquivos CSV/planilhas.

## ✨ Funcionalidades
- Importação e leitura estruturada de dados de alunos e listas de aprovados
- Algoritmo de correspondência e normalização de nomes/documentos
- Painel web para consulta, validação e visualização de resultados

## 🛠️ Tecnologias
- PHP 8.2+ & Laravel
- SQLite / MySQL
- Blade, HTML5, CSS3 & JavaScript

## 🚀 Instalação
```bash
git clone https://github.com/willams502/Desafio-Chromos-v2-.git
cd Desafio-Chromos-v2-
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan serve
```

## 🧪 Testes
```bash
php artisan test
```
